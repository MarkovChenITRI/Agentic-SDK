## 各類授權帶來的義務

| 授權 | 散布時要做什麼 |
| --- | --- |
| MIT | 保留版權聲明與授權全文 |
| BSD-3-Clause | 保留版權聲明與授權全文，不得以原作者名義背書 |
| Apache-2.0 | 保留 NOTICE，修改過的檔案要標示 |
| MPL-2.0 | 檔案層級 copyleft，僅在修改該套件原始檔時觸發；本專案未修改 |
| PSF-2.0 | 保留版權聲明 |

這份檔案由 `scripts/generate_third_party_notices.py` 產生，改動依賴後重新執行它。
