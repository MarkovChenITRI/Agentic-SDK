# 技術 Blog

AI Hub 將模型、執行環境與硬體條件整理成模型卡，並將部署後的模型服務以 OpenAI 相容介面提供給應用程式使用。Agentic SDK 則讓應用程式把這些服務放進工作流程，安排輸入理解、資料查找、回覆、工具操作與安全檢查。

本區記錄三項整合設計。三篇文章都清楚區分目前已公開的技術能力，以及仍待實作與驗證的產品整合；它們不是既有功能的操作說明。

## 文章

- [用 Letta 將對話整理成可保存的長期記憶](reflect-letta.md)：讓長對話經過整理後保存，並在後續對話中找回需要的內容。
- [用 Fara 看懂畫面並操作電腦](action-fara.md)：將視覺電腦操作模型部署成服務，交由工作流程在安全限制下執行操作。
- [用 MatrAIx 的角色設定產生不同風格的回覆](action-matraix.md)：使用版本化的角色設定資料，引導同一個文字模型產生不同風格的回覆。

每篇文章都會說明可交付的資產、推論服務、工作流程的責任，以及需要保存哪些版本與測試記錄，才可以將整合標示為已驗證。
