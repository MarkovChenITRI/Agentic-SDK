# 允許破壞相容性，並讓使用者知道怎麼固定版本

## 這件事要解決什麼

`pip install git+https://github.com/R300-AI/Agentic-SDK.git` 永遠裝到最新的 `main`。SDK 的模組介面要調整時，這等於讓每個既有使用者在不知情的狀況下被破壞。

## 決定

允許破壞性變更，但配套三件事：README 教使用者指定標籤、發布 `0.2.0`、變更紀錄寫清楚改了什麼。

## 使用者故事

**US1** — 我照 README 安裝，裝到的是一個固定的版本，不會有一天突然壞掉。

**US2** — 我要升級時，看得到這一版改了哪些介面、我要怎麼跟著改。

## 邊界

不維持舊介面的相容層。這個 SDK 還在早期，背相容包袱的成本高過收益；代價由版本標籤和變更紀錄承擔。
