# 07: 多行程時明確拒絕啟動

**What to build:** 有人為了效能加上多個 worker 時，Playground 啟動就拒絕並說明原因，而不是照常啟動然後讓插話靜默失效。

**Blocked by:** 無，可立即開始

**Status:** done

- [x] 啟動時偵測 worker 數量，多於一個就拒絕並說明原因
- [x] 錯誤訊息指出這是插話功能的要求，不是效能設定錯誤
- [x] 原因寫在啟動程式旁邊，讓改設定的人在改之前就看得到

## 為什麼

插話訊號和它要停止的工作流必須共用記憶體。多 worker 時中斷請求可能落在另一個行程，插話就再也不會生效——而且**不會有任何錯誤**。

靜默失效是最糟的失敗模式。這個專案今天才花了整天在追同一類問題：系統照常運作，但做的事和畫面說的不一樣。
