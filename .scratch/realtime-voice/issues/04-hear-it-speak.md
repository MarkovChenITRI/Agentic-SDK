# 04: 聽它講

**What to build:** Agent 一邊在畫面上給出精確資料，一邊用口語講出重點與判斷理由。兩者互相補充，不是把畫面上的字唸一遍。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] `VoiceAnswerAction` 繼承 `GenerativeAction`，既有模組一行不動
- [ ] 一次生成產出**說出的內容**與**顯示的內容**兩個頻道
- [ ] 說出的內容一完成就送去合成，不等顯示的內容生成完
- [ ] 沒有說出的內容的 action 退回唸顯示的內容——能動，只是照本宣科
- [ ] 合成串流可被取消
- [ ] 假傳輸能驗證兩個頻道與退回行為

## 為什麼輸出在 action 不在 perceive

說話就是 action。曾考慮讓 perceive 同時擁有兩個方向，理由是「一個地方擁有音訊通道」——但轉寫是長連線、合成是每次回答一條串流請求，兩者不共用任何東西。見 `docs/adr/0001-where-voice-lives.md`。

## 為什麼不被 02、03 擋

語音輸出不需要語音輸入。可以和打斷那條線平行做。
