# 02: 講到一半打斷它

**What to build:** Agent 正在回答時使用者開口，Agent 就停下來。停止的原因回報為「被打斷」，不是錯誤。

**Blocked by:** 01

**Status:** done

- [x] Perceiver 的背景監聽在其他模組執行中觸發插話
- [x] 工作流停止，`interrupted` 為真，不是 `aborted` 的錯誤路徑
- [x] 軌跡上看得出這一輪是被打斷的，以及打斷發生在哪個模組執行中
- [x] 連續打斷多次不會讓工作流劣化（重訪計數不累積）
- [x] 假傳輸能觸發打斷，測試不需要真實語音

## 已經在核心裡的部分

取消權杖、`Workflow.run(cancel=...)`、串流中的取消點、`interrupted` 與 `aborted` 的區分，都已由 spike 完成並有測試。這張是把 Perceiver 接上那個機制。

打斷靠語音活動偵測，不等轉寫：實測開口到偵測約 610 ms，完整轉寫約 3.9 秒。等文字就不叫打斷了。
